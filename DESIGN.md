# Project portfolio design

Editorial project index: warm paper, dark ink, quiet rules, one large real project image. Project source links lead; employment, skill inventories and visitor counters are absent.

- Background: #f5f3ed. Text: #242824. Secondary: #62665d. Rule: #cecec3.
- Accent: #a83c22. Featured surface: #e4e8de.
- Typeface: Manrope, 400–800. Display 43–90px; section headings 30–44px; body 13–19px.
- Desktop: 64px gutters, 1600px maximum shell. Mobile: 22px gutters below 700px.
- Rows and typography carry the project directory; category buttons filter without hiding content when JavaScript is unavailable.
- Keyboard-visible focus rings, skip link, live result counts, and reduced-motion support.
- Real MANTIS screenshot sourced from SanjaySparker27/mantis_painter, docs/assets/nose_camera_dynamic.jpg. It depicts simulation, not hardware performance.
